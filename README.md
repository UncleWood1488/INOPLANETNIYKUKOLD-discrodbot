# Основные файлы и их функции:
emoji.py:

Содержит данные о пользовательском эмодзи "skufcoin", который используется в качестве валюты в боте.

functions.py:

Основной файл с функциями бота. Включает:

Работа: Пользователи могут зарабатывать скуфкоины, выполняя команду /work.

Магазин: Пользователи могут тратить скуфкоины в магазине.

Музыкальный плеер: Пользователи могут воспроизводить музыку из YouTube.

Игры: Реализованы игры, такие как блэкджек и рыбалка.

Перемещение пользователей: Администраторы могут перемещать пользователей между голосовыми каналами.

Баланс: Пользователи могут проверять свой баланс скуфкоинов.

main.py:

Основной файл, который запускает бота и обрабатывает события, такие как подключение бота, сообщения и команды.

Реализованы команды, такие как /work, /bj (блэкджек), /fishing (рыбалка), /balance (проверка баланса), /move (перемещение пользователей) и другие.

music_cog.py:

Класс для управления музыкальными командами, такими как воспроизведение и остановка музыки.

musicplayer.py:

Реализация музыкального плеера, который использует библиотеку yt-dlp для воспроизведения музыки из YouTube.

config.py:

Содержит конфигурационные параметры, такие как токен бота, префикс команд, настройки прокси, кулдауны для команд и настройки выплат за различные действия.

# Основные команды бота:
/work: Заработок скуфкоинов.

/bj: Игра в блэкджек.

/fishing: Рыбалка.

/balance: Проверка баланса скуфкоинов.

/move: Перемещение пользователей между голосовыми каналами.

/play: Воспроизведение музыки из YouTube.

/stop: Остановка музыки.

/shop: Магазин для покупки предметов.

/help: Справка по командам.

# Особенности:
Экономика: Бот использует валюту "скуфкоины", которую пользователи могут зарабатывать и тратить.

Игры: Реализованы мини-игры, такие как блэкджек и рыбалка, которые добавляют интерактивность.

Музыкальный плеер: Пользователи могут воспроизводить музыку из YouTube в голосовых каналах.

Административные функции: Администраторы могут перемещать пользователей между голосовыми каналами.

# Запуск бота:
Для запуска бота необходимо установить зависимости из файла requirements и запустить файл main.py. Токен бота должен быть указан в config.py или в переменных окружения.
